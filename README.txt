SHEMAN. Portfolio - plain HTML / CSS / JavaScript (no React, no Node needed)
Chalane ka tareeqa: index.html ko browser mein double-click karke kholein.
Content badalne ke liye js/script.js ke upar wala C = {...} edit karein. C.assets mein project/logo images ka folder hai (abhi live site se load hota hai; apni images assets/images/ mein copy karke "assets/images/" likh dein).
Note: contact form backend se connected nahi hai; WhatsApp number set karne par WhatsApp khulta hai.

IMAGES: project aur logo images pehle local folder se load hoti hain:
  assets/images/project/   (catwalk.jpg, amroz.jpg, mz-collection.png ...)
  assets/images/logo/      (lamia.png, nasamo.png ...)
Agar wahan nahi milti to aapki live site se load hoti hain (internet chahiye). Dono nahi milein to rang wala placeholder dikhta hai.
Live preview (claude.ai) bahar ki images block karta hai, isliye wahan placeholder hi dikhega - ZIP kholein.
